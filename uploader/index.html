Channel Uploader

Channel Uploader (shown on Google's sign-in screen as "GTA Channel Uploader") is a private tool that publishes our own videos to our own accounts: the "GTA 6" YouTube channel and the "What If Daily Sports" pages on Instagram and TikTok.

What it does

  • Uploads finished videos, with their titles, descriptions and tags, to the channel owner's own YouTube channel through the YouTube Data API.
  • Reads the view counts of those same videos so we can see which ones work.
  • Posts the same kind of videos to the owner's own TikTok and Instagram accounts.

Who uses it

Only the channel owner. It is not offered to the public, it does not sign in anyone else, and it does not collect data about viewers.

Uses YouTube API Services

Channel Uploader uses YouTube API Services. By using it you agree to the YouTube Terms of Service. See the Google Privacy Policy and our Privacy Policy. Access can be revoked at any time at Google security settings.
